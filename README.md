# Keep Jelly
Make game for LÖVE Jam 2026-B

A 2D-Puzzle-Platformer game with some jelly physics effects.

---

Controls:

f5 - restart

escape - return to menu

a - move left

d - move right

spacebar - jump

e - pick up items
